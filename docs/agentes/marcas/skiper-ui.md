# Skiper UI experiment (effects lab)

Scope: `src/features/skiper/**` and the "Experimento · Skiper UI" project in the Space (page "Laboratório", created 2026-10-05).

- An experiment, not a client: the user asked to "test a page with effects like" the free components of Skiper UI (`https://skiper-ui.com/components?source=free`, React + Framer Motion + Lenis). The page is a lab: each section shows one effect, named with its Skiper number (`[ 02 ] skiper16`). Builds in `.space/experimento-skiper-ui/build/lab/` (session wrapper `build/sp.sh`); `build/page.ts` + `build/cdp.mjs` render the page with the app's engine and check it in Edge without the dev server (desktop, phone, `reduce`).
- The free license requires credit to Skiper UI: the footer ("Créditos") links skiper-ui.com, names the author (Gurvinder Singh) and lists every component used (`SK_COMPONENTS`). Keep it on any page that reuses these effects.
- Look of the Skiper demos: paper `#f5f4f3`, ink `#0a0a0a`, orange `#ff5800` (skiper28), lime `#c2f84f`, petrol `#1f3a4b` and cream `#fafdee` (skiper19), mist `#eeeeee` (skiper30); Geist for everything, Geist Mono for indexes and micro labels; the "role para ver" label with a 64px hairline under it; cards 32px. Photos are the generated section-library set (`public/sections/c25/businesses`). The numbers on the page count the page itself (13 components, 9 sections, 1 script, 0 plugins besides Elementor); update them if that changes.
- Effects (`src/features/skiper/motion.ts`, one behavior-only HTML widget, first child of the header; GSAP 3.13, ScrollTrigger and Lenis 1.3 from jsDelivr): Lenis smooth wheel; pill header with letter-roll links (skiper58, CSS only); progressive blur at the top and bottom of the screen (skiper41, three fixed `backdrop-filter` layers per edge); scroll-progress ring that goes back to the top (skiper89); hero letters gathering from the center while spinning in X, then spreading as the hero leaves (skiper31); sticky card stack that shrinks (skiper16); lime SVG stroke that follows the page (skiper19, `shapes.ts`): it starts from the first point (the user, 2026-10-05: "deve vir desde o primeiro ponto, fazendo todo o efeito"), the loops draw while the title crosses the screen, then the tip stays at 60% of the viewport height down to the numbers card, and it erases when scrolling back up. The drawing is scaled per device (0.8/0.6/0.3) so the loops wrap the end of the title and never pass the right edge of the screen; rolling digits (skiper37); four parallax photo columns (skiper30); 3D perspective paragraph (skiper28, the box is 300vh only under `html.sk-live`); photo strips that open on hover, tap or Tab, vertical on phones (skiper52/53); hand-drawn SVG mask with zoom on hover (skiper66) and a spring-following dot (skiper61, mouse only).
- The CSS alone is the final composition: the full stroke is a CSS background until the script swaps in the animated SVG, the stack is pure `position: sticky`, the columns are centered and taller than their box, the paragraph sits at its final tilt, the strips open on CSS hover. Reduced motion, the Elementor editor and non-scrolling pages (Space thumbnails) run nothing; the strips and the ring still work there. Whatever GSAP moves has no transition (`sk-move`, `.e-con` transitions limited to background, border and shadow), and no Elementor entrance animations.
