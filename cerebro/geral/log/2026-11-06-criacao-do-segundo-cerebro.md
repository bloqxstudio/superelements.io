# Criação do segundo cérebro

**Data:** 2026-11-06 · **Iniciativa:** geral · **Quem:** Igor, com o Claude Code

## O que aconteceu

Igor pediu uma base de conhecimento da empresa no repositório, com uma pasta por iniciativa: contexto do que
estamos construindo, como estamos, o próximo passo, e logs com imagens e criativos.

## O que entregamos

- A pasta `cerebro/` com o painel [AGORA.md](../../AGORA.md), cinco iniciativas e modelos de nota.
- `npm run cerebro:log` (novo log) e `npm run cerebro:midia` (imagens e vídeos já leves para o Git).
- Os READMEs e as decisões iniciais tirados do `AGENTS.md` como estava neste dia.

## O que aprendemos

O repositório já tem 1,2 GB de histórico Git e não tem Git LFS: por isso a mídia entra comprimida
(WebP até 1600 px, MP4 até 1280 px) e nada acima de 50 MB.

Revisar os READMEs das iniciativas e corrigir o que estiver fora da realidade.
